    1. A tour of RStudio

    RStudio is an integrated development environment (IDE) for R, a programming language widely used for data analysis, statistical modeling, and visualization.

    RStudio has four main panes:

    Pane What it does
    Source (top left) Where your scripts open. You write code here.
    Console (bottom left) Where R runs code and shows you the answer.
    Environment (top right) Everything you’ve stored so far.
    Files / Plots / Packages / Help (bottom right) Your folders, your plots, your packages, and help pages.

    1.1 The Console

    The Console is where you directly interact with R. You can type R commands, hit Enter, and see the immediate results.

    Key Features:

    • Executes code line-by-line.
    • Useful for quick calculations or testing small snippets of code.
    • Does not save commands. Once you close RStudio, the history of commands in the Console is gone unless explicitly saved.

    TRY: write 2 + 2 in the console and press Enter.

    What does [1] mean in the answer? It means “here is the first item of the answer.” Ignore it for now. It will make sense in Section 7.

    1.2 The Terminal

    The Terminal is separate from the Console and provides access to your computer’s command-line interface (CLI).

    • The Console is for R.
    • The Terminal is for your computer (for example, Git or managing files).

    We will not use Terminal most of the time

    1.3 Scripts

    A script is a text file where you write and save R code for future use.

    • Scripts let you document your work, making it reproducible and shareable.
    • You can save time by re-running pre-written code instead of typing commands repeatedly.

    How to Create and Use a Script:

    • Click on File → New File → R Script.
    • Write R code in the script editor. E.g.
    x <- 5
y <- 10
z <- x + y
print(z)
    ## [1] 15
    • Put your cursor on a line (or highlight several lines) and press Ctrl+Enter (Windows/Linux) or Cmd+Enter (Mac) to run it in the Console.
    • Save your script often: File → Save.

    Two helpful tricks:

    • If the Console shows a + instead of >, R thinks your code isn’t finished (usually a missing ) or "). Click in the Console and press Esc.
    • Lines that start with # are comments. R skips them. More on this in Section 4.3.

    2. Projects and folders

    2.1 RStudio Projects

    An RStudio Project is a way to organize your work by grouping files, data, and scripts for a specific task or analysis.

    Why Use Projects?

    • Keeps your workspace clean and focused.
    • Automatically sets the working directory to the project folder.
    • Ensures reproducibility by keeping everything needed for a project in one place.

    How to Create a Project:

    1. Click on File → New Project…..
    2. Choose New Directory → New Project.
    3. Give it a clear name (example: EMS747_Project)
    4. Choose a location you can easily find again (like your Desktop or Documents)

    When you create a project, RStudio makes a file ending in .Rproj. Always open your work by clicking that .Rproj file.

    2.2 Organize your project folder

    Inside your project folder, create these folders:

    • data/ for datasets (CSV, Excel, etc.)
    • scripts/ for R scripts you write during the semester

    In RStudio: use the Files pane → New Folder.

    Your project should look like this:

    EMS747_Project/
  EMS747_Project.Rproj
  data/
  scripts/
  bigdata_L1.R

    2.3 Your working directory

    The working directory is the folder R is looking at right now. When your project is open, it should be your project folder. Check it:

    getwd()

    In words: “get the working directory.”

    You should see a path ending in your project folder name.

    Why this matters

    At the end of today (Section 9), we load a dataset from your data/ folder using a short path like:

    read_csv("data/my_file.csv")

    This only works if R is looking at your project folder.

    3. R Packages

    • Packages are collections of R functions, data, and compiled code.
    • They extend what base R can do.
    • Someone else wrote them, so you don’t have to.

    Think of it like a book:

    • install.packages() buys the book and puts it on your shelf. You do this once per computer.
    • library() takes the book off the shelf so you can use it. You do this every time you open R.

    In this class we use the tidyverse. It’s a bundle of packages that work well together, including dplyr, tidyr, readr, stringr, ggplot2, and lubridate.

    Installation (once):

    install.packages("tidyverse")

    Loading (every time):

    library(tidyverse)

    Notice: the name is in quotes in install.packages("tidyverse") but not in library(tidyverse).

    When you load it, R prints a list of the packages it turned on. That’s a message, not an error.

    Check the package documentation with ?

    ?dplyr

    N.B. Packages only need to be installed once but must be loaded in each session library(). Keep packages updated with update.packages()

    4. R: Basic Grammar

    4.1 Storing things: assignment

    Doing math is nice, but the answers disappear. To keep something, we give it a name. This is called assignment.

    apple <- 5
apple
    ## [1] 5

    In words: “apple gets 5.”

    What just happened?

    • R made a box, wrote “apple” on the label, and put the number 5 inside it.
    • The left side (apple) is a name you make up.
    • The arrow <- means “store whatever is on the right into the name on the left.” Type it as < followed by -. Shortcut: Alt + - (Windows) or Option + - (Mac).
    • Storing is quiet. Nothing prints until you type the name.
    • Look at your Environment pane: apple is there now.

    There are three ways to assign:

    = (Simple Assignment) Similar to python

    <- (Leftward Assignment) Most Common used by R coders and we will use this

    -> (Rightward Assignment) Rarely used

    x = "Simple_Assignment"
print(x)
    ## [1] "Simple_Assignment"
    y <- "Leftward Assignment"
print(y)
    ## [1] "Leftward Assignment"
    "Rightward_Assignment" -> z
print(z)
    ## [1] "Rightward_Assignment"

    If you store something new under a name that already exists, the old value is replaced. R does not warn you.

    apple <- 10
apple
    ## [1] 10

    You can use stored values in math, and store the result in a new box:

    banana <- 3
fruit_total <- apple + banana
fruit_total
    ## [1] 13

    In words: “fruit_total gets apple plus banana.”

    4.2 R is case-sensitive

    x <- 2

print(X)
    ## Error in eval(expr, envir, enclos): object 'X' not found

    It gave an error, why?

    Cause R is case sensitive . x and X are two different names.

    print(x)
    ## [1] 2

    “object ‘X’ not found” is the most common error you will see. Check your spelling and capital letters first.

    4.3 Comments

    Comments are notes in the code that R ignores. Use # to write comments.

    • R only has single line comments, so if you want multiple lines you need to repeat the # for each line.
    • A comment can go on its own line or at the end of a line of code.
    variable_2 <- "Leftward Assignment" ## this is the most common used by R coders
# Other's work as well

    4.4 Names you can and can’t use

    Rules for names:

    • Start with a letter: candy1 works, 1candy does not.
    • No spaces. Use underscores: fruit_total, not fruit total.
    • Be descriptive: study_hours is better than sh.

    Reserved keywords: these words already mean something to R, so you cannot use them as names.

    Words Description
    if, else Used for conditional execution of code.
    for, while, repeat Loops.
    function Defines a function.
    TRUE, FALSE Logical values (yes/no).
    NULL The absence of a value.
    NA Missing data (“Not Available”).
    Inf Infinity (e.g., division by zero).
    NaN “Not a Number” (e.g., 0 / 0).

    5. Data Types

    5.1 Numeric, Character, Logical, Factor

    Every value in R has a type.

    • Numeric: Numbers
      • e.g., 3.14, 42
    • Character: Text or strings, always in quotes
      • e.g., "Hello", "R"
    • Logical: yes/no values
      • TRUE, FALSE
    • Factor: Categorical data
      • e.g., "Masters", "PhD" (we’ll use these later in the semester)

    You can use typeof() to see what type of data it is

    TRY: Writing different data types

    age <- 25  # Numeric
typeof(age)
    ## [1] "double"
    name <- "Alice"  # Character
typeof(name)
    ## [1] "character"
    is_student <- TRUE  # Logical
typeof(is_student)
    ## [1] "logical"

    What does typeof() do? It asks R: “how are you storing this value inside the computer?” Every value has exactly one storage type.

    Question? What is double?

    R has two ways to store numbers:

    typeof() says What it is Example How you make it
    "double" Any number, decimals allowed 25, 3.14, -2 Just type the number
    "integer" Whole numbers only 25L, 1:5 Add an L, or use :
    • “Double” is short for “double precision.” R stores each number with about 15-16 digits of accuracy. The name comes from computer history: it uses twice the memory of an older “single precision” format. You don’t need to know more than that.
    • Every number you type is a double, even a whole number like 25. That’s why typeof(age) above says "double", not "integer".
    • Integers show up on their own when you make a sequence with : (Section 7.4). Don’t be surprised when you see "integer" there.
    • For your work, both just mean “number.” Math works the same on both. To ask “is this a number?”, use is.numeric():
    typeof(25)       # a number you type: double
    ## [1] "double"
    typeof(25L)      # the L makes it an integer
    ## [1] "integer"
    typeof(1:5)      # a sequence made with : is integer
    ## [1] "integer"
    is.numeric(25)   # is it a number? yes
    ## [1] TRUE
    is.numeric(1:5)  # is it a number? yes
    ## [1] TRUE

    You will see these types again, shortened. When you print a tibble or use glimpse() (Sections 8 and 9), R labels each column with a short version of its type:

    typeof() Short label in a tibble Means
    "double" <dbl> number
    "integer" <int> whole number
    "character" <chr> text
    "logical" <lgl> TRUE/FALSE

    So when you see <dbl> next to a column, it means “this column is numbers.”

    Quotes matter. 5 is a number. "5" is text that happens to look like a number. You can’t do math with text:

    "5" + 1   # this gives an error ON PURPOSE
    ## Error in "5" + 1: non-numeric argument to binary operator
    5 + 1
    ## [1] 6

    5.2 Asking TRUE/FALSE questions

    R answers yes/no questions with TRUE or FALSE. We’ll use this all semester to keep only the rows we want.

    Symbol Question
    == is equal to?
    != is not equal to?
    > < is greater / less than?
    >= <= is greater / less than or equal to? 
    age > 18           # "is age greater than 18?"
    ## [1] TRUE
    age == 30          # "is age equal to 30?"
    ## [1] FALSE
    age != 30          # "is age NOT equal to 30?"
    ## [1] TRUE
    "Boston" == "boston"   # capital letters count!
    ## [1] FALSE

    <- STORES. == ASKS. age <- 30 puts 30 in the box. age == 30 asks “is there a 30 in the box?”

    One handy trick: R treats TRUE as 1 and FALSE as 0. Remember this, it comes back in Section 7.

    TRUE + TRUE + FALSE
    ## [1] 2

    6. Basic Arithmetic

    Operators in R:

    Operator Meaning
    + Addition
    - Subtraction
    * Multiplication
    / Division
    ^ Exponentiation (power)

    TRY

    a <- 10
b <- 3

sum <- a + b  # Addition
print(sum)
    ## [1] 13
    product <- a * b  # Multiplication
print(product)
    ## [1] 30
    power <- a ^ b  # Exponentiation
print(power)
    ## [1] 1000

    R follows the usual math order: powers first, then * and /, then + and -. Use parentheses to be safe:

    2 + 3 * 4     # 3 * 4 first, then + 2
    ## [1] 14
    (2 + 3) * 4   # 2 + 3 first, then * 4
    ## [1] 20

    7. Vectors

    A vector is a list of values of the same type, stored under one name. Almost everything in R is built from vectors. Every column in a dataset is a vector.

    7.1 Creating Vectors

    • Creating Vectors: Use the c() function. c stands for combine.

    TRY

    numbers <- c(1, 2, 3, 4, 5)  # Numeric vector
names <- c("Alice", "Bob", "Charlie")  # Character vector
is_student <- c(TRUE, FALSE, TRUE)  # Logical vector

    In words: “numbers gets the combination of 1, 2, 3, 4, and 5.”

    TRY what types they are

    typeof(numbers)
    ## [1] "double"
    typeof(names)
    ## [1] "character"
    typeof(is_student)
    ## [1] "logical"

    Vectors can hold text too:

    fruits <- c("Banana", "Mango", "Strawberry", "Grapes")  # ADD YOUR FAVORITES!
fruits
    ## [1] "Banana"     "Mango"      "Strawberry" "Grapes"

    7.2 Getting items out: indexing

    You can access an element in a vector with square brackets []. fruits[3] means “the 3rd item of fruits.”

    fruits[3]  # Third item
    ## [1] "Strawberry"
    fruits[c(1, 4)]  # First and fourth items
    ## [1] "Banana" "Grapes"
    fruits[2:3]  # Items 2 through 3
    ## [1] "Mango"      "Strawberry"
    fruits[-2]  # Everything EXCEPT the second item
    ## [1] "Banana"     "Strawberry" "Grapes"

    Now [1] in your answers makes sense: it tells you the position of the first item on that line.

    Practice:

    • How do you select only items 1, 3, and 5?
    • How do you exclude items 2 and 4?
    # Selecting items:
fruits[c(1, 3, 5)]
    ## [1] "Banana"     "Strawberry" NA
    # Excluding items:
fruits[-c(2, 4)]
    ## [1] "Banana"     "Strawberry"
    # Saving a subset:
favorite_fruits <- fruits[c(1, 3)]
favorite_fruits
    ## [1] "Banana"     "Strawberry"

    Why is there an NA above? fruits only has 4 items, so there is no item 5. R gives NA, which means “missing.”

    7.3 Vector functions

    Functions are R’s built-in tools. The pattern is always:

    function_name(what_you_give_it)
    study_hours <- c(2, 5, 3, 8, 4)

length(study_hours)   # how many items
    ## [1] 5
    mean(study_hours)     # average
    ## [1] 4.4
    max(study_hours)      # biggest
    ## [1] 8
    min(study_hours)      # smallest
    ## [1] 2
    sum(study_hours)      # add them all up
    ## [1] 22

    Some functions take more than one input, separated by commas. round() takes a number and how many decimal places you want:

    round(mean(study_hours), 1)
    ## [1] 4.4

    Read nested functions from the inside out: “take the mean of study_hours, then round it to 1 decimal.”

    Asking a question of a whole vector gives one TRUE/FALSE per item:

    study_hours > 4
    ## [1] FALSE  TRUE FALSE  TRUE FALSE

    Because TRUE = 1 and FALSE = 0 (Section 5.2), sum() counts the TRUEs and mean() gives the proportion:

    sum(study_hours > 4)    # how many days were more than 4 hours?
    ## [1] 2
    mean(study_hours > 4)   # what proportion of days?
    ## [1] 0.4

    Some functions don’t work on every type:

    # Vector properties
length(fruits)       # Number of elements
    ## [1] 4
    fruits * 2           # Produces an ERROR
    ## Error in fruits * 2: non-numeric argument to binary operator

    7.5 Combining Vectors & Type Coercion

    Combine vectors of different types:

    numbers <- 1:5
text <- "Hello"

combo
    ## [1] "1"     "2"     "3"     "4"     "5"     "Hello"

    Type Coercion:

    • A vector can only hold one type, so R converts everything to the same type.
    • Order of precedence:
      • Character > Numeric > Logical.
    typeof(numbers)      # "integer"
    ## [1] "integer"
    typeof(text)         # "character"
    ## [1] "character"

    7.6 Vector Arithmetic & Recycling

    We can also do arithmetic with vectors! R does it item by item:

    c(1, 2, 3) + c(10, 20, 30)
    ## [1] 11 22 33

    In words: 1 + 10, 2 + 20, 3 + 30.

    What will happen if we use vectors of different sizes?

    D <- 20:24
E <- 25:30

D+E
    ## [1] 45 47 49 51 53 50

    R applies recycling which means…

    • D (length 5) is recycled to match the length of E (length 6).

    • D becomes: 20, 21, 22, 23, 24, 20 (repeating the first element).

    • Then, element-wise addition is performed:

      • (20 + 25), (21 + 26), (22 + 27), (23 + 28), (24 + 29), (20 + 30) = 45, 47, 49, 51, 53, 50

    R gives you a warning when this happens. Recycling is usually a mistake, so check your lengths!

    8. Data Frames: base R and tidy

    A data frame is a table where each column is a variable (a vector) and each row is an observation. Think of it as a spreadsheet.

    • Each column can be a different type (numeric, character, logical).
    • Every column must have the same length!!

    8.3 Base R vs. tidy: the same task two ways

    Reminder: R has two “dialects.” Base R is what comes with R. The tidyverse is a set of packages with a cleaner, more readable style. You will see both online, in old code, and from ChatGPT. In this class we write tidy code, but you should be able to recognize base R when you see it.

    Here is the same task in both dialects. Look for the patterns:

    Task Base R Tidy
    Get one column df$Age people |> pull(Age)
    Pick columns df[, c("Name", "Age")] people |> select(Name, Age)
    Keep rows df[df$Age > 25, ] people |> filter(Age > 25)
    Sort df[order(df$Age), ] people |> arrange(Age)
    Sort, biggest first df[order(-df$Age), ] people |> arrange(desc(Age))
    Add a column df$Grad <- c(2021, 2026, 2019) people |> mutate(Grad = c(2021, 2026, 2019))
    Average of a column mean(df$Age) people |> summarise(mean_age = mean(Age))

    Keep rows where Age is over 25:

    # Base R
df[df$Age > 25, ]
    ##    Name Age Professor
## 2 Jessy  30     FALSE
## 3 Chris  35      TRUE

people |>
  filter(Age > 25)
    ## # A tibble: 2 x 3
##   Name    Age Professor
##   <chr> <dbl> <lgl>    
## 1 Jessy    30 FALSE    
## 2 Chris    35 TRUE

    8.4 The pipe |>

    The |> symbol is called the pipe. Read it as “and then.” It takes what’s on the left and hands it to the function on the right.

    The pipe lets you chain steps, top to bottom, like a recipe:

    people |>
  filter(Age > 25) |>
  arrange(desc(Age))
    ## # A tibble: 2 x 4
##   Name    Age Professor Graduation
##   <chr> <dbl> <lgl>          <dbl>
## 1 Chris    35 TRUE            2019
## 2 Jessy    30 FALSE           2026

    In words: “start with people, and then keep the rows where Age is over 25, and then sort by Age, oldest first.”

    Without the pipe, you would have to read it inside out:

    arrange(filter(people, Age > 25), desc(Age))
    ## # A tibble: 2 x 4
##   Name    Age Professor Graduation
##   <chr> <dbl> <lgl>          <dbl>
## 1 Chris    35 TRUE            2019
## 2 Jessy    30 FALSE           2026

    Same answer, much harder to read.

    Shortcut: Mac: Cmd + Shift + M, Windows: Ctrl + Shift + M

    To make the shortcut type |>: Tools → Global Options → Code → check “Use native pipe operator, |>”. Online you will also see %>%. It’s an older pipe that does almost the same thing.

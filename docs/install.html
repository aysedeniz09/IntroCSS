How to Install R, RStudio, and Git

Before the First Class

You need three things on your laptop:

What Why When
R The programming language Before class 1
RStudio The program you write R in Before class 1
Git + a GitHub account To publish your dashboard at the end of the semester Before class 2 (Assignment 1)

It is very important to install in order: first R, then RStudio.

Step 1: Install R

Download R from CRAN: https://cran.r-project.org/

  • Mac: click “Download R for macOS” and pick the installer for your chip (Apple Silicon for M1/M2/M3/M4, Intel for older Macs).
  • Windows: click “Download R for Windows”, then “base”, then the download link.

Open the downloaded file and follow the steps. You will not open R directly; you will use it through RStudio.

Step 2: Install RStudio

Install RStudio Desktop (free) AFTER you installed R: https://posit.co/download/rstudio-desktop/

RStudio already includes Quarto, which we use for dashboards. To check: in RStudio, go to File → New File. You should see Quarto Document… in the list.

Step 3: Install the Packages

Open RStudio. Go to File → New File → R Script, paste this code in, highlight it, and run it with Ctrl + Enter (Windows) or Cmd + Enter (Mac). It can take 10 minutes or more. That’s normal.

install.packages("tidyverse")           # data wrangling and plots
install.packages("tidytext")            # text analysis
install.packages("textdata")            # sentiment dictionaries
install.packages("quanteda")            # key word in context (KWIC)
install.packages("quanteda.textplots")  # KWIC plots
install.packages("topicmodels")         # topic modeling
install.packages("httr2")               # collecting data from APIs
install.packages("jsonlite")            # reading API data
install.packages("igraph")              # networks
install.packages("ggraph")              # network plots
install.packages("DT")                  # interactive tables for dashboards
install.packages("devtools")            # installing packages from GitHub

Then install ldaOptim (for choosing the number of topics) from GitHub:

devtools::install_github("aysedeniz09/ldaOptim")

Check that it worked. Run these lines. If you see no red Error messages, you’re ready. (Messages about packages being “attached” or “masked” are fine.)

library(tidyverse)
library(tidytext)
library(quanteda)
library(topicmodels)
library(httr2)
library(igraph)
library(ldaOptim)

Step 4: Install Git and Make a GitHub Account (Assignment 1, due Feb 1)

At the end of the semester you publish your dashboard on GitHub. We set it up now, so any problems show up early.

4a. Make a GitHub account

Sign up at https://github.com/. Pick a username you’re happy to share: it will be part of your dashboard’s web address.

4b. Install Git

  • Mac: open RStudio, click the Terminal tab (next to the Console), type git --version, and press Enter. If Git isn’t installed, your Mac will offer to install the “command line developer tools.” Click Install and wait.
  • Windows: download Git from https://git-scm.com/download/win and run the installer. The default options are fine. Restart RStudio afterwards.

4c. Check that Git works

In the RStudio Terminal tab, type:

git --version

You should see something like git version 2.x.x.

4d. Tell Git who you are

In the same Terminal, type these two lines, with your own name and the email you used for GitHub:

git config --global user.name "Your Name"
git config --global user.email "your_email@bu.edu"

4e. Submit Assignment 1

On Blackboard, submit:

  1. Your GitHub username
  2. A screenshot of git --version working in your RStudio Terminal

Getting Help

For help with any function, type ? followed by the function name and run it:

?filter
?ggplot

If you have any issues with installation, email the instructor or TA, or come to office hours. Don’t wait until the night before: installation problems are easy to fix early.

Troubleshooting

Package installation fails

  • Make sure you’re connected to the internet
  • Close RStudio, reopen it, and try again
  • Install the failing package by itself and read the error message

RStudio won’t open, or says it can’t find R

  • Make sure R is installed first
  • Try reinstalling RStudio

Can’t load a package (“there is no package called…”)

  • Install it first with install.packages()
  • Check the spelling and capital letters

git --version says “command not found” (Windows)

  • Restart RStudio after installing Git
  • In RStudio: Tools → Global Options → Git/SVN, check that the Git path is filled in (usually C:/Program Files/Git/bin/git.exe)

Your files are in OneDrive, iCloud, or Dropbox

  • Syncing folders can cause errors with R projects and Git. Keep your class project in a regular folder, like Documents.
